# report-cloud (비공개)
PC가 꺼져 있어도 도는 시세·공개자료 리포트. 비밀값은 GitHub Secrets에만.

| 리포트 | 상태 |
|---|---|
| 히트맵(미장 S&P500·국장 350) | 클라우드 시험 중 · 결과는 Actions 실행 기록에만(공개 전) |

- 시세: 야후 v8 일봉만. 네이버·pykrx·핀비즈 자동 접속 금지.
- 미장 시총: 클라우드 IP는 야후 시총 조회가 막혀 `cache/us_caps_ref.json`(기준일 시총) × 그 뒤 주가 변화로 추정.
- 국장 종가는 야후 기준(임시), 공식 종가와 다를 수 있음.
